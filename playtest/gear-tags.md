# Gear Tags

## General

|             |                                                           |
| ----------- | --------------------------------------------------------- |
| *bulky*     | Takes up 2 inventory slots.                               |
| _concealed_ | Hidden to the naked eye. Undetectable without technology. |
| *loud*      | Easily heard by anyone within 100 metres.                 |
| *petty*     | Does not take up any inventory slots.                     |
| *quiet*     | Difficult to hear by anyone further away than 2 metres.   |
| *slow*      | Wielder cannot act first at the start of combat.          |


## Combat

|               |                                                                                                                                                                        |
| ------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| *autofire*    | Weapon can perform **Burst** or **Suppress** attack actions.                                                                                                           |
| *blast*       | Attacks affect all targets in the area, rolling damage separately for each target. If unsure how many targets can be affected, roll the related damage die for result. |
| *destructive* | Attacks destroy cover.                                                                                                                                                 |
| _parry_       | Wielder has +1 Armor against melee attacks.                                                                                                                            |
| *piercing*    | Attacks ignore Armor.                                                                                                                                                  |
| *precise*     | Attacks are _impaired_ on the same turn you move.                                                                                                                      |
| *reload*      | Consumes one ammo per attack                                                                                                                                           |
| _retro_       | Cannot use special ammo.                                                                                                                                               |
| *shock*       | Target must succeed on a BOD save or fall prone.                                                                                                                       |
| *shred*       | If attack deals damage to Stamina or BOD, target's Armor is reduced by 1                                                                                               |
| _smart_       | Attacks ignore Light Cover. Requires a Smartlink to use.                                                                                                               |
| _static_      | Cannot be used if wielder has moved this turn.                                                                                                                         |
| _unreliable_  | Weapon jams when rolling a one on any dice during an attack roll. Takes an action to unjam.                                                                            |
