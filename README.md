Hardware is a cyberpunk role-playing game of survival in a dark future of criminals, corporations, opportunity, and a city that grinds away your humanity. Character generation is quick, scenarios are tense and reward careful planning, combat is fast-paced, tactical and deadly.

The full text is licensed under [CC-BY-SA 4.0](https://creativecommons.org/licenses/by-sa/4.0/). You can find the source files [here](https://github.com/joecargill/hardwarerpg).

Inspired by Neuromancer & Cyberpunk 2077, the rules are built upon [Cairn](https://cairnrpg.com).
